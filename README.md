## About these notes

These are **my own notes in my own words** — what I understood, how it connects to work
I've actually done, and the questions I had along the way. No course material, exercise
text, solution code or datasets are reproduced here. Anything under `practice/` is written
by me against public datasets.

If a note only made sense as a copy of the course, it wouldn't be worth writing.
