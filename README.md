# DataCamp Learning Log

My notes and practice work from DataCamp, on a **DataCamp Donates scholarship awarded
through [Data Engineering Pilipinas](https://dataengineering.ph/)**, August 2026 onward.

Starting with the Data Engineer path. Data Science and Data Analyst tracks follow, so this
repo is organised to hold all of them rather than just the first.

Every course gets a note written here as it is finished. This is the dated record of the
work, not a highlight reel.

**Lorenzo Gabriel Pineda**, BS Business Administration, major in Business Intelligence and
Analytics (De La Salle-College of Saint Benilde, 2026).

## About these notes

These are **my own notes in my own words**: what I understood, how it connects to work I
have actually done, and the questions I still have. No course material, exercise text,
solution code or datasets are reproduced here. Anything under `practice/` is written by me
against public datasets.

If a note only made sense as a copy of the course, it would not be worth writing.

## Layout

```
notes/
  associate-data-engineer-sql/   one note per course, in my own words
  data-engineer-python/          (starts when the track does)
practice/                        queries and scripts I wrote against public datasets
archive/ds4b/                    earlier coursework, before the DataCamp path
```

Notes are foldered by track rather than numbered in one long sequence. Tracks overlap, and
the same topic taught twice in two different tracks should be two separate notes, not one
note quietly overwritten.
